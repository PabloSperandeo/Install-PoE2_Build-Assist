# PoE2 Build Assist — instaladores

Este repositório guarda só os instaladores do PoE2 Build Assist (sem código).

## Como instalar

1. Abra a página [Releases](https://github.com/PabloSperandeo/Install-PoE2_Build-Assist/releases/latest).
2. Baixe `PoE2-Build-Assist-Setup-<versão>.exe` e execute.
3. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo** (o instalador não tem assinatura digital).

O instalador traz o Path of Building 2 junto (atalho "Path of Building 2"). Depois da primeira instalação, as versões novas chegam sozinhas: o app avisa "Versão X pronta" e instala ao reiniciar ou ao fechar.

Para usar a IA do app é preciso ter o [Ollama](https://ollama.com) instalado.

## Garantias

O app não lê a memória, a tela nem os processos do jogo, não envia teclas nem cliques, e não fala com servidores da GGG. O atualizador só conversa com este repositório no GitHub.
